# D1を直接操作する

このアプリのDB名は **my-tools-web-db**、Workerからのバインディング名は **DB** です。

## Cloudflareの画面から

1. [Cloudflareダッシュボード](https://dash.cloudflare.com/)にログインします。
2. 左メニューの **Storage & Databases → D1 SQL database** を開きます。
3. **my-tools-web-db** を選択します。
4. **Studio**（テーブル表示）や **Console**（SQL実行）でデータを確認します。表示名はダッシュボードの版により異なります。

ユーザー情報の確認例です。

```sql
SELECT id, name, email, role, createdAt
FROM "user"
ORDER BY createdAt DESC
LIMIT 100;
```

## ターミナルから

プロジェクトのフォルダーで以下を実行します。

```sh
npx wrangler login
npx wrangler d1 execute my-tools-web-db --remote --command='SELECT id, name, email, role FROM user LIMIT 100'
```

- `--remote`: 公開サイトで使用している本番DB。
- `--local`: 自分のPC内の開発用DB。本番データとは別です。
- SQLファイルを実行する場合は `--command` の代わりに `--file <ファイル名>` を指定します。

## 主なテーブル

| テーブル | 用途 |
| --- | --- |
| user | ユーザーID、表示名、メール、権限 |
| account | ログイン用のアカウントとパスワードハッシュ |
| session | ログインセッション |
| verification | 認証ライブラリーの検証用データ |
| rateLimit | 認証APIのアクセス回数 |
| adminSetup | 一度限りの初期管理者設定の状態 |
| d1_migrations | 適用済みのマイグレーション |

アカウント作成は、アプリの管理者用「アカウント管理」画面を使います。SQLへ平文パスワードを書き込む方法ではログインできません。スキーマ変更は `migrations/` で管理します。
